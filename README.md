# Finishline Online Karting

The kart racing simulator of Finishline Performance in Biloxi, Mississippi.
Race the Tidal Turns, Cadet 206 Practice and Karting Coastal layouts in the
rental R25, the LO206, the Vintage Kart or the KA100, against the clock or
against your friends online.

**Play in your browser:** https://finishline-online-karting.netlify.app

## Download the app

Get the newest version from **[Releases](../../releases/latest)**:

- **Mac** (Intel and Apple Silicon): `Finishline-Online-Karting-…-mac.dmg`.
  Open it and drag the app into Applications.
- **Windows** (64-bit): `Finishline-Online-Karting-…-win.exe`. Run it to
  install.

The app needs an internet connection. It always runs the latest version of
the game, so you only download it once.

### "Can't be opened" or "Windows protected your PC"?

The app isn't signed with a paid Apple or Microsoft certificate yet, so the
first time you open it:

- **Mac:** right-click (or Control-click) the app in Applications, choose
  **Open**, then **Open** again. If macOS still refuses, go to **System
  Settings → Privacy & Security** and click **Open Anyway**.
- **Windows:** click **More info**, then **Run anyway**.

After that it opens normally.

## Controls

| | Keyboard | Gamepad |
|---|---|---|
| Throttle | W / ↑ | RT |
| Brake | S / ↓ / Space | LT |
| Steer | A D / ← → | Left stick |
| Camera | C | Y |
| Turn kart around | F | X |
| Reset to track | R | B |
| Menu | Esc | Start |
| Full screen (app) | F11 | |

Steering wheels and pedals work too: set them up under **Controls** in the game.
